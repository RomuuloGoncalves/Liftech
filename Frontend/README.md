# Frontend Liftech

Aplicação web do projeto Liftech. A interface permite que gestores e administradores visualizem dados de telemetria, gerenciem empilhadeiras e acompanhem incidentes em tempo real.

## Tecnologias Principais
- React com Vite
- TypeScript
- Redux (Gerenciamento de estado)
- Ant Design (Biblioteca de UI)
- Axios (Comunicação com a API)
- React Router (Navegação)

## Como Iniciar

A inicialização do frontend faz parte da configuração do Monorepo. Execute o comando de inicialização na raiz do projeto principal para rodar o ambiente completo:

```bash
# Na pasta raiz do projeto
yarn dev
```

Se precisar rodar apenas o frontend de forma isolada, entre nesta pasta e inicie o servidor do Vite:

```bash
cd Frontend
yarn dev
```
